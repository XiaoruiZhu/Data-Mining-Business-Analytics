Introduction to Classification and Regression Trees 1

  • Decision trees are a popular supervised data mining technique.
  • Output displayed as one or more upside-down trees. Easy to interpret. Represents a set of if-then rules.
  • There are three types of nodes.
    • Root node: top node of tree, first variable to which a split is applied (branches).
    • Interior node: more decision rules applied.
    • Leaf/terminal node: classification or predictions given, no more splitting.

Introduction to Classification and Regression Trees 2

  • Example: Recall the HELOC introductory case.
  • If age < 50 and income < 100k, then the customer will not respond.
  • If age < 50 and income >= 100k, then the customer will respond.
  • If age >= 50 and income < 50k, then the customer will not respond.
  • If age >= 50 and income >= 50k, then the customer will respond.

Introduction to Classification and Regression Trees 3

  • The splitting process is repeated until each subset contains only cases with similar values for the target variable.

  • Pure subsets consist of leaf nodes that contain cases with the same value of the target variable.

  • Splitting unitl there is no need to further split pure subsets.

  • The process is recursive.

Introduction to Classification and Regression Trees 4

  • Categorical target variable: classification tree
    • classify class membership of future cases.
    • classification tree performance measures: confusion matrix; ROC, AUC
  • Numerical target variable: regression tree
    • predict the value of the outcome variable of future cases.
    • regression tree performance measures: RMSE, ME, MAD, MAE, MPE, and MAPE.
  • Note: built tree model using training data set, then improve tree model using test data set.

Regression Trees

  • Regression trees are constructed using the CART algorithm, which works similarly for classification and regression trees.

  • There are three key differences:

    • The target variable is numerical.
    • The predicted value is the average value of the cases that belong to the same leaf node.
    • Use MSE rather than the Gini index to measure impurity.

  • Tree performance measures: RMSE, ME, MAD, MAE, MPE, and MAPE.
